# Asset Provenance

This file tracks third-party assets that may be included in distributable builds of TheNexus.

Development-only third-party anime reference packs are **not** distributable official assets and should not be listed here as if they were licensed product content. They must remain isolated and excluded from release artifacts.

## Rules

For every third-party asset intended for official distribution, record:

- repository path or asset package;
- asset/title description;
- author/creator;
- original source URL;
- license name and version;
- license/source URL;
- required attribution text;
- modifications made;
- whether commercial distribution is permitted;
- whether redistribution of modified versions is permitted;
- date verified;
- verification notes.

If licensing is unclear, do not include the asset in a distributable build.

## Development-only content

Known-character anime packs used locally for development/testing must live behind the development-only asset boundary and be excluded from public/commercial release packaging. Do not copy/rip commercial sprite sheets into the repository for redistribution.
